# Lobo do Vitória Shell

A cabeça geométrica de lobo prateado e lilás aprovada pelo usuário substitui o gato usado como símbolo da central de controle. A imagem original foi copiada sem edição para [assets/vitoria-wolf.png](../assets/vitoria-wolf.png), preservando transparência RGBA. A barra e as configurações usam WolfIcon.qml e o identificador vitoria-wolf. O gato animado da GPU não foi alterado.

Criado com a ferramenta integrada image_gen. Prompt final:

Use case: logo-brand. Create one polished original geometric wolf-head emblem as a candidate symbol for Vitória Shell, a Windows desktop shell. Single centered front-facing wolf head, clear upright pointed ears, tapered muzzle, balanced near-symmetry. Build the silhouette from a small number of bold angular polygon facets, elegant low-poly geometry with subtle dimensional beveled shading. Cool silver and soft lavender facets, charcoal facial features, restrained pale icy-blue eyes. Strong readable silhouette at 22px toolbar icon size, broad shapes, no fine fur or thin outlines. Calm alert expression, recognizable WOLF rather than fox or cat. Square composition, isolated on genuinely transparent background with generous clean padding, no badge/container, no lettering, no words, no watermark, no extra objects. This is a standalone icon concept preview, not a UI mockup.

Validação: PNG RGBA, 1254 × 1254, alpha de 0 a 255; prévia renderizada no Qt em 110 px e 22 px, conferida visualmente. Atualização da barra iniciada sem erros. O ícone nativo QIcon no executável usará a imagem após recompilar; a barra e os símbolos das configurações carregam a imagem diretamente.
